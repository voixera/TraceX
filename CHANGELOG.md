# Changelog

All notable changes to TraceX will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-08-29

### Added
- Initial release with core architecture
- FastAPI REST API
- CLI with Typer and Rich
- Telegram Bot with aiogram
- Web Dashboard with Next.js
- Domain intelligence collector
- URL intelligence collector
- GitHub intelligence collector
- Username intelligence collector
- Relationship graph engine
- Case management system
- Evidence tracking
- Docker Compose setup
- PostgreSQL database models
- Redis caching support
- Unit tests
- CI/CD workflows

### Features
- Multi-interface support (CLI, Bot, Web)
- Modular collector system
- Normalized entity format
- Relationship inference
- Report generation
- Rate limiting
- Configurable API keys

### Security
- Secure password hashing
- API key encryption
- Audit logging
- Data retention policies

- README.md
